テーマ方針

カスタムテーマ（スクラッチ）またはシンプルなスターターテーマをベースに制作してください。既製テーマ（Cocoon等）はカスタマイズの制約が多くなるため非推奨です。
  • テーマ名（任意）：bni-shin 推奨
  • 必要テンプレート：front-page.php（トップ）、archive-member.php（メンバー一覧）、header.php、footer.php
  • スタイル：カラー・フォントはこのドキュメント末尾の「デザイン仕様」を参照

カスタム投稿タイプ：member

メンバー情報はカスタム投稿タイプ member で管理します。将来的にメンバー自身が更新できることを想定した設計にしてください。

投稿タイプ定義（functions.php に追記）

function bni_register_member_post_type() {
    register_post_type( 'member', [
        'labels' => [
            'name'               => 'メンバー',
            'singular_name'      => 'メンバー',
            'add_new_item'       => 'メンバーを追加',
            'edit_item'          => 'メンバーを編集',
            'all_items'          => 'メンバー一覧',
        ],
        'public'       => true,
        'has_archive'  => true,
        'rewrite'      => [ 'slug' => 'members' ],
        'supports'     => [ 'title', 'thumbnail', 'custom-fields' ],
        'menu_icon'    => 'dashicons-groups',
        'show_in_rest' => true,
    ]);
}
add_action( 'init', 'bni_register_member_post_type' );

カスタムフィールド（ACF または add_post_meta）

フィールド名（キー）表示ラベル型必須
member_category業種カテゴリーテキスト◯
member_commentひとことコメントテキストエリア◯

氏名は投稿タイトル、写真はアイキャッチ画像として登録します。

メンバー一覧の出力例（archive-member.php）

<div class="members-grid">
  <?php while ( have_posts() ) : the_post(); ?>
    <div class="member-card">
      <?php if ( has_post_thumbnail() ) : ?>
        <div class="member-photo"><?php the_post_thumbnail('medium'); ?></div>
      <?php endif; ?>
      <div class="member-info">
        <div class="member-name"><?php the_title(); ?></div>
        <div class="member-biz"><?php echo esc_html( get_post_meta( get_the_ID(), 'member_category', true ) ); ?></div>
        <div class="member-comment"><?php echo esc_html( get_post_meta( get_the_ID(), 'member_comment', true ) ); ?></div>
      </div>
    </div>
  <?php endwhile; ?>
</div>
